## 🎯 FLUJO RECOMENDADO

### Primer Día (Conocer la App)
```
1. Leer LEEME_PRIMERO.md (5 min)
2. Ejecutar: INICIO.bat (Windows) o ./inicio.sh (Mac/Linux)
3. Explorar la interfaz (10 min)
4. Probar como oyente (sin login) (5 min)
5. Probar como DJ (con login) (5 min)
6. Leer GUIA_RAPIDA.md (10 min)
```

### Segundo Día (Entender el Sistema)
```
1. Leer ARQUITECTURA_v2.md (15 min)
2. Revisar código en src/ (30 min)
3. Ver base de datos en Supabase (10 min)
4. Leer ADMIN_GUIDE.md (20 min)
```

### Tercer Día (Modificar - Si Eres Developer)
```
1. Leer DEVELOPER_GUIDE.md (30 min)
2. Leer SETUP_SUPABASE.md (10 min)
3. Crear rama nueva: git checkout -b feature/mi-feature
4. Hacer cambios
5. Testear
6. Commit y push
```
